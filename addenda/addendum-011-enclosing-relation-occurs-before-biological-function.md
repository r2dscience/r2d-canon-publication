# Addendum 11 — Enclosing Relation Occurs Before Biological Function

## Boundary-Owned Function, Structural Constraint, and Recursive Replacement Beyond Protein Structure

## Abstract

Biology is often summarized by the sequence

$$\text{sequence}\longrightarrow\text{structure}\longrightarrow\text{function}.$$

Addendum 10 showed that the first arrow is not the persistence of one molecular identity through scale.

A folded protein is an enclosing structural state that replaces many subordinate conformational realizations
and many possible folding histories:

$$\pi_{\mathrm{fold}}:\Omega_{\mathrm{conf}}\longrightarrow\mathcal M_{\mathrm{fold}}.$$

Protein structure is therefore boundary owned.

The present addendum asks whether biological function is contained within that structure.

It is not.

Structure constrains which functions are physically possible, but realized function requires an enclosing
relation in which the structural state participates.

A motor protein does not contain mechanical work in isolation.

Work requires a mechanical constraint and a distinguishable displacement.

An enzyme does not realize catalysis in isolation.

Catalysis requires an enzyme-substrate-product reaction boundary.

A receptor does not realize signaling in isolation.

Signaling requires a relation containing ligand, receptor state, and an enclosing network in which a
downstream distinction is produced.

Thus structure defines an admissible set of possible functional relations, but the realized function belongs
to a larger boundary.

<!-- source_pdf_page: 1203 -->

Let $S_i$ denote a structural state and E denote the relevant enclosing physical relation.

Define a functional classification

$$\pi_{\mathrm{func}}:\Omega_S\times\Omega_E\longrightarrow\mathcal M_{\mathrm{func}}.$$

Then a functional state

$$F_j\in\mathcal M_{\mathrm{func}}$$

is not a property of $S_i$ alone.

Rather,

$$F_j=\pi_{\mathrm{func}}(S_i,E).$$

The same structural state can participate in different functions when the enclosing relation changes:

$$(S_i,E_1)\longrightarrow F_1,$$

$$(S_i,E_2)\longrightarrow F_2.$$

Likewise, different subordinate structural realizations can produce the same enclosing function:

$$(S_1,E_1),(S_2,E_2),\ldots\in\pi_{\mathrm{func}}^{-1}(F_j).$$

The multiplicity of a functional state is therefore

$$W_{\mathrm{func}}(j)=\left|\pi_{\mathrm{func}}^{-1}(F_j)\right|.$$

Function introduces another recursive replacement.

The protein structure remains physically necessary.

But its detailed structural identity is not identical to the enclosing functional state.

The function is defined only on the boundary at which its consequence becomes distinguishable.

This relation is directly visible in muscle.

The spectroscopically resolved myosin switch is organized by

$$A_M=P_M-R_M.$$

The switch structure alone does not specify muscle force.

<!-- source_pdf_page: 1204 -->

Mechanical function emerges only within an enclosing relation containing chemical possibility, mechanical
constraint, switch realization, and displacement.

Thus structure realizes function without containing function.

The central statement is:

**Protein structure constrains the set of biological functions that can be physically realized, but struct…**

Hence:

> **Enclosing relation occurs before biological function.**

Here “before” denotes causal and boundary ownership, not earlier laboratory time.

## 1. Structure Does Not Complete the Biological Hierarchy

Addendum 10 established that a folded protein is not one microscopic configuration.

It is an enclosing structural state:

$$\pi_{\mathrm{fold}}:\Omega_{\mathrm{conf}}\longrightarrow\mathcal M_{\mathrm{fold}}.$$

Many subordinate conformational realizations can belong to one persistent structure:

$$W_F(i)=\left|\pi_{\mathrm{fold}}^{-1}(F_i)\right|.$$

The fold therefore represents a new boundary.

But a folded protein is not yet a biological function.

A further boundary relation is required.

## 2. The Familiar Sequence–Structure–Function Chain Compresses Two Replacement Steps

The conventional shorthand

> sequence → structure → function

is useful, but ontologically compressed.

R²D expands the first arrow as:

<!-- source_pdf_page: 1205 -->

> sequence + enclosing compatibility
>
> ⇓
>
> structural multiplicity landscape
>
> ⇓
>
> folded state.

The second arrow must likewise be expanded.

A structure participates in an enclosing relation before a functional state can be defined.

Thus:

> structure + enclosing relation → functional statehood.

## 3. Structure and Function Are Different State Domains

Let

$$S_i$$

denote a protein structural state.

Let

$$F_j$$

denote a biological functional state.

R²D does not identify them:

$$S_i\ne F_j.$$

A structure can be necessary for a function without being identical to the function.

The distinction is the same one developed throughout the preceding addenda:

> **realizer is not the enclosing state.**

<!-- source_pdf_page: 1206 -->

## 4. Biological Function Is Defined at the Scale of Its Consequence

A function becomes physically distinguishable only on the boundary at which its consequence can be
counted.

Muscle contraction is defined at the muscle boundary.

Catalytic turnover is defined at the reaction boundary.

Signal transmission is defined at a signaling boundary.

Transport is defined relative to compartments across which transport occurs.

Mechanical work is defined relative to force and displacement.

Thus:

> function ownership follows the boundary of the functional consequence.

## 5. A Protein Can Possess Functional Capability Without Realizing Function

A folded structure can make certain interactions physically possible.

That structural capability is real.

But capability is not the same as realized function.

Let

$$\mathcal A(S_i)$$

denote the set of functional relations physically admissible to structural state $S_i$.

Then:

$$S_i\longrightarrow\mathcal A(S_i).$$

The structure constrains what can happen.

It does not by itself select which function is currently realized.

<!-- source_pdf_page: 1207 -->

## 6. The Enclosing Relation Selects a Realized Function

Let

$$E$$

denote the relevant enclosing physical relation.

Then a realized functional state can be written schematically as

$$F_j=\Phi(S_i,E).$$

More formally:

$$\pi_{\mathrm{func}}:\Omega_S\times\Omega_E\longrightarrow\mathcal M_{\mathrm{func}}.$$

The structural state and enclosing relation together determine which functional distinction is realized.

## 7. Function Is Therefore Relational

The map

$$\pi_{\mathrm{func}}$$

acts on a relation, not on isolated structure alone.

Thus:

$$F_j\ne\pi_{\mathrm{func}}(S_i)$$

in general.

Instead:

$$F_j=\pi_{\mathrm{func}}(S_i,E).$$

This is the central boundary-ownership statement.

## 8. Structure Constrains Function but Does Not Contain It

The appropriate R²D statement is therefore:

> structure constrains function;

<!-- source_pdf_page: 1208 -->

> enclosing relation defines realized function.

This does not diminish the importance of protein structure.

Without the appropriate structural state, the functional relation may be inadmissible.

But structural necessity does not imply functional ownership.

## 9. The Same Structure Can Participate in Different Functions

Suppose the structural state remains

$$S_i.$$

Under enclosing relation $E_1$,

$$(S_i,E_1)\longrightarrow F_1.$$

Under another relation $E_2$,

$$(S_i,E_2)\longrightarrow F_2.$$

Therefore:

$$S_i\not\Rightarrow F_j.$$

uniquely.

The functional state requires specification of the enclosing relation.

## 10. The Same Function Can Be Realized by Different Structures

The inverse relation can also be many-to-one.

Different structural realizations may support the same enclosing function:

$$(S_1,E_1)\longrightarrow F_j,$$

$$(S_2,E_2)\longrightarrow F_j.$$

Thus:

> **functional identity does not imply unique structural identity.**

<!-- source_pdf_page: 1209 -->

This is another recursive replacement.

## 11. Functional Statehood Has Multiplicity

For functional state $F_j$,

$$W_{\mathrm{func}}(j)=\left|\pi_{\mathrm{func}}^{-1}(F_j)\right|.$$

This multiplicity counts the subordinate structural-environmental realizations that are degenerate with
respect to the functional boundary.

Thus:

> subordinate structural identity → functional multiplicity.

The same architecture now extends from molecular conformation to structure and from structure to
function.

## 12. Functional Multiplicity Is Not Functional Ambiguity

If several subordinate realizations produce the same functional state, the function is not poorly specified.

It is precisely specified at the functional boundary.

The ambiguity exists only if one attempts to reconstruct a unique subordinate realization from the
enclosing functional read.

Thus:

> functional definiteness

can coexist with

> subordinate structural degeneracy.

This is already familiar from the myosin ensemble.

## 13. Myosin Provides the Direct Experimental Example

The myosin switch possesses spectroscopically resolvable states:

$$M_1$$

<!-- source_pdf_page: 1210 -->

and

$$M_2.$$

Yet Addendum 4 showed that the molecular state distribution does not uniquely determine the muscle-
scale mechanical state.

Instead:

$$A_M=P_M-R_M.$$

The local molecular realization depends on chemical possibility and enclosing mechanical retention.

Thus:

> **myosin state is not muscle function.**

The functional boundary is larger.

## 14. Muscle Force Is Not Intrinsic to Myosin Structure

A myosin molecule can possess the structural capability to bind, switch, and generate displacement.

But muscle force requires an enclosing mechanical relation.

A mechanical constraint must exist.

The molecular displacement must occur relative to that constraint.

Thus force belongs to the muscle-scale mechanical boundary.

It cannot be assigned to myosin structure alone.

## 15. Mechanical Work Makes the Relational Character Explicit

In R²D, retained possibility has the physical form

$$R=C\lambda.$$

Both terms are required.

If

$$C=0,$$

<!-- source_pdf_page: 1211 -->

there is no retained mechanical bias.

If

$$\lambda=0,$$

there is no distinguishable displacement against the constraint.

Mechanical work therefore does not reside inside the protein.

It exists only in the relation:

> constraint × distinguishable displacement.

## 16. A Motor Protein Structure Defines Capability, Not Completed Work

The myosin structure makes a mechanical displacement admissible.

But:

> **myosin structure is not mechanical work.**

Work requires:

> motor structure + chemical possibility + mechanical constraint + displacement.

The resulting functional state belongs to the enclosing mechanical relation.

## 17. The Stall Condition Makes This Especially Clear

At active isometric stall:

$$A_M=0$$

and

$$P_M=R_M.$$

The myosin switch remains physically realized.

The chemical possibility remains nonzero.

<!-- source_pdf_page: 1212 -->

The mechanical retention remains nonzero.

Yet macroscopic shortening vanishes.

The protein structure has not disappeared.

The functional relation has changed.

This alone shows that structure and function cannot be identical.

## 18. Enzyme Catalysis Has the Same Architecture

Consider an enzyme structural state

$$S_E.$$

The isolated structure may possess a binding pocket and catalytic geometry.

But realized catalysis requires an enclosing chemical relation containing, at minimum, the appropriate
substrate and reaction environment.

Schematically:

$$S_E+\text{substrate}+\text{reaction environment}\longrightarrow F_{\mathrm{cat}}.$$

Catalytic capability belongs to structure.

Catalytic realization belongs to the reaction boundary.

## 19. Catalysis Is Defined by a New Distinguishable Chemical Consequence

A catalytic function is physically readable when an enclosing reaction distinguishes:

$$\text{substrate}\longrightarrow\text{product}.$$

The enzyme participates in that transition.

But the function is not defined by the enzyme structure in isolation.

The relevant count domain includes the reaction relation itself.

Thus:

<!-- source_pdf_page: 1213 -->

> enzyme structure → admissible catalysis,

while

> enzyme + reaction boundary → realized catalytic function.

## 20. Receptor Signaling Has the Same Architecture

A receptor has structural states.

Those structures constrain ligand binding and interaction with downstream partners.

But signaling is not identical to receptor conformation.

A signaling function requires a boundary containing:

> ligand,
>
> receptor state,
>
> downstream distinguishable response.

Thus:

> receptor structure + enclosing signaling network → signaling function.

## 21. Transport Is Also Relational

A transporter structure may possess the capability to bind and translocate a substrate.

But transport is defined only relative to distinct sides of a boundary.

Without the enclosing compartment relation, there is no distinguishable transport function.

Thus:

  transporter structure + compartment relation + substrate asymmetry → transport function.

Again, structure constrains realization.

The enclosing relation owns the function.

## 22. Biological Function Therefore Requires a New Boundary

The transition from structure to function is not merely another descriptive label attached to the same
object.

It introduces a new count domain.

At the structural boundary:

$$S_i$$

is the state.

At the functional boundary:

$$F_j$$

is the state.

The function classifies relations among subordinate structures and their environments.

Thus:

> structure → recursive replacement → function.

## 23. A Functional Boundary Replaces Structural Detail

Many subordinate structural details may change without altering the enclosing function.

For example, if several conformational realizations all sustain the same catalytic turnover class, mechanical
state, or signaling output, then those structural differences are degenerate relative to the functional
boundary.

Thus:

$$S_1,S_2,\ldots\in\pi_{\mathrm{func}}^{-1}(F_j).$$

The functional state does not require every subordinate structural coordinate to remain readable.

<!-- source_pdf_page: 1215 -->

## 24. Structure Is Therefore a Realizer of Function

A structural state is physically necessary for its compatible functions.

But after the functional boundary is defined, the structure occupies the same conceptual position that the
molecular trajectory occupied relative to the fold.

It is a subordinate realizer.

Thus:

> structure realizes function

without implying:

> structure is function.

## 25. Function Can Remain Stable While Structure Fluctuates

A functional state may persist while subordinate structural dynamics continue.

Thus:

$$S(t)\text{ fluctuates within an admissible class}$$

while

$$F_j\text{ remains unchanged}.$$

This is the function-scale analogue of a folded protein remaining structurally stable while its subordinate
molecular coordinates fluctuate.

## 26. Stable Function Does Not Require One Frozen Structure

If function required a single exact subordinate conformation, then any structural fluctuation would destroy
function.

Biological systems do not generally behave that way.

R²D instead predicts:

> functional persistence = persistence of enclosing compatibility

<!-- source_pdf_page: 1216 -->

across a multiplicity of admissible subordinate realizations.

## 27. Functional Robustness Is Therefore a Replacement Property

Many different subordinate changes can leave the function unchanged.

This robustness can be represented as a large preimage:

$$\left|\pi_{\mathrm{func}}^{-1}(F_j)\right|>1.$$

Functional robustness is therefore not merely tolerance of error.

It can be a direct consequence of many-to-one boundary classification.

## 28. Functional Failure Occurs When the Enclosing Classification Changes

A structural perturbation becomes functionally significant when the realized relation crosses into a different
functional macrostate:

$$\pi_{\mathrm{func}}(S_i,E)=F_j$$

but after perturbation:

$$\pi_{\mathrm{func}}(S_i^{\prime},E^{\prime})=F_k,\qquad F_k\ne F_j.$$

Not every structural change is therefore a functional change.

Function is boundary relative.

## 29. Structural Change Can Be Silent at the Functional Boundary

A protein may undergo:

$$S_i\longrightarrow S_i^{\prime}$$

while:

$$F_j\longrightarrow F_j.$$

At the structural boundary, something changed.

<!-- source_pdf_page: 1217 -->

At the functional boundary, nothing did.

The structural distinction has been replaced relative to function.

## 30. Conversely, Functional Change Need Not Require a New Protein Fold

The enclosing relation can change while the protein remains in the same structural class.

For example:

$$S_i=\text{constant},$$

while:

$$E_1\longrightarrow E_2$$

produces:

$$F_1\longrightarrow F_2.$$

This is decisive evidence that function cannot be assigned to structure alone.

## 31. Context Dependence Is Boundary Dependence

Biologists often describe function as context dependent.

R²D gives this statement a precise physical meaning.

“Context” is the enclosing relation needed to define the functional boundary.

Thus:

> context dependence = boundary dependence.

Function changes when the enclosing count domain changes.

## 32. This Is Not Subjectivity

The word “context” should not imply observer dependence.

The relevant context is physical:

- binding partners;
- mechanical load;
- substrate availability;
- membrane geometry;
- electrical or chemical gradients;
- cellular network state;
- tissue constraint;
- other enclosing relations.

Thus:

> functional context = physical enclosing relation.

## 33. The Structure–Function Relationship Is Therefore Asymmetric

Structure constrains what functions are admissible.

Function does not emerge from arbitrary structure.

But the realized function is defined at a boundary larger than structure.

Thus:

$$S_i\longrightarrow\mathcal A(S_i)$$

while:

$$E\longrightarrow F_j\in\mathcal A(S_i).$$

This preserves the causal importance of structure without making function intrinsic to isolated structure.

## 34. Structure Defines Possibility; Enclosing Relation Defines Realization

This can be stated compactly:

> structure → functional possibility,

> enclosing relation → functional realization.

<!-- source_pdf_page: 1219 -->

## 35. Functional Statehood Is Not Created by the Component

The protein participates in the function.

It does not create the state domain in which the function is defined.

That domain exists only when the relevant enclosing distinctions are present.

Thus:

> **component mechanism is not the functional state.**

The same distinction was already required for myosin switching and muscle force.

## 36. This Generalizes the Myosin Causal Inversion

## 37. Function Can Be Created or Destroyed Without Destroying the Structure

If the enclosing relation is removed, the function may disappear even though the protein remains folded.

A motor without load can remain structurally intact.

A receptor without the relevant signaling relation can remain structurally intact.

> **loss of function does not imply loss of structure.**

The functional boundary has disappeared while the structural boundary persists.

$$S_i\longrightarrow S_k$$

$$\mathcal A(S_i)\longrightarrow\mathcal A(S_k).$$

R²D does not replace structural biology.

## 56. Conclusion

The familiar statement that protein structure determines biological function is useful but incomplete.

Structure is indispensable.

A protein's fold constrains its binding surfaces, mechanics, chemistry, conformational possibilities, and
interactions.

It therefore constrains the set of functions that can be physically realized.

But a structural state is not itself a realized function.

A function becomes physically distinguishable only when the protein participates in an enclosing relation.

For structural state $S_i$, define its admissible functional set:

$$\mathcal A(S_i).$$

<!-- source_pdf_page: 1229 -->

The structure constrains this set.

A particular function is realized only when the structure participates in an enclosing physical relation E :

$$F_j=\pi_{\mathrm{func}}(S_i,E).$$

Thus:

> structure constrains function;

but:

> enclosing relation defines realized function.

The myosin system provides the direct experimental example.

The resolved myosin switch does not uniquely determine muscle force.

Its occupancy asymmetry is organized by:

$$A_M=P_M-R_M.$$

Chemical possibility and mechanical retention belong to an enclosing relation.

The molecular switch realizes that relation.

Mechanical work further requires both constraint and displacement:

$$R=C\lambda.$$

Neither quantity resides in the isolated protein.

The function belongs to the relation.

The same architecture applies to enzyme catalysis, receptor signaling, transport, and other biological
processes.

A structure can make a function possible.

But realized function requires a substrate, a load, a ligand, a gradient, a network, a compartment, or
another enclosing relation in which a new distinguishable consequence occurs.

This produces another many-to-one replacement.

Different subordinate structural realizations can yield the same function:

<!-- source_pdf_page: 1230 -->

$$(S_1,E_1),(S_2,E_2),\ldots\longrightarrow F_j.$$

Their number defines functional multiplicity:

$$W_{\mathrm{func}}(j)=\left|\pi_{\mathrm{func}}^{-1}(F_j)\right|.$$

Conversely, the same structural state can participate in different functions when the enclosing relation
changes:

$$(S_i,E_1)\longrightarrow F_1,$$

$$(S_i,E_2)\longrightarrow F_2.$$

Function is therefore boundary owned.

This completes the biological replacement sequence.

Subordinate molecular dynamics are replaced by structural statehood.

Structural statehood participates in another enclosing relation and is replaced by functional statehood.

The hierarchy is not:

> one molecular identity → more complicated versions of itself.

It is:
