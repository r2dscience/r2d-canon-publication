# R²D Canon authority

Effective 2026-10-07, I, Josh E. Baker, designate the following files in this Quarto project as the authoritative editable Markdown sources of R²D Canon Parts I–IV:

- `canon/part-i.md`
- `canon/part-ii.md`
- `canon/part-iii.md`
- `canon/part-iv.md`

These files supersede the 2026-09-25 authoritative Markdown packages as editable masters. The earlier packages remain provenance snapshots. The date of this authority transfer is separate from the scientific revision recorded within each Part.

The Quarto HTML and PDF, generated retrieval files, and Ask R²D corpus are derived from these masters. Future approved changes to Parts I–IV are made here first, then rendered and propagated to Ask R²D.

Part I governs primitive definitions. Parts II–IV retain the logical status of each claim as stated in their text. Addenda retain their separate authority and are not transferred by this declaration.

## Authority of the Canon and Addenda

Effective with the commit containing this declaration, `canon/part-i.md` through `canon/part-iv.md` are the authoritative editable texts of Canon Parts I–IV. The Markdown files in `addenda/` that are listed in `_quarto.yml` are the authoritative editable texts of their respective addenda.

Part I governs the primitive definitions and count architecture. Parts II–IV develop that architecture. Addenda remain downstream of the Canon: authoritative text status does not give an addendum primitive authority or change its internal distinctions among derivation, postulate, physical mapping, hypothesis, and unresolved question.

Earlier authoritative packages remain provenance snapshots. Quarto HTML and PDFs, generated files, and the Ask R²D retrieval corpus are derived from these editable sources. Changes to this publication do not update Ask R²D automatically.

An addendum becomes part of this authoritative publication only when its source file and status have been reviewed, it is listed in `_quarto.yml`, and the change is committed. Missing addendum numbers do not imply missing publication files.
